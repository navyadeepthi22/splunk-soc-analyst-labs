# Lab 01: Log Ingestion in Splunk

## Objective

Learn how to ingest log data into Splunk for security analysis.

## Tool

Splunk Enterprise

## Procedure

1. Open Splunk Enterprise.
2. Navigate to Add Data.
3. Upload the sample CSV log dataset.
4. Configure the source type and index.
5. Search the ingested events using Splunk Search.

## Verification

Verify that the uploaded events appear in Splunk and that the expected fields are extracted correctly.

## Learning Outcome

Learned the basic process of bringing log data into Splunk for analysis.
